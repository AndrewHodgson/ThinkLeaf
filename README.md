# Thinkleaf

Thinkleaf is a note-first visual workspace for project-based thinking.

It combines structured meeting notes, project organization, custom tags, search, and light whiteboard tools in one calm interface.

## MVP Goal

Create a local prototype where users can:

- Create projects
- Create folders inside projects
- Create pages inside folders
- Add tags to pages
- Write structured notes
- Draw beside notes
- Search notes
- Autosave everything locally
