# Thinkleaf Codex Instructions

This folder contains reusable instructions for Codex so prompts can stay short.

Before starting work, read:

- `project-vision.md`
- `notes/current-status.md`
- `codex/guardrails.md`
- `codex/next-task.md`

The project vision defines the product direction.
The current status file defines what is already working.
The guardrails file defines what not to break or overbuild.
The next-task file defines the specific task to complete.
